# Launch checklist

Check each item before publishing a site. Mark features that the site does not use as not applicable.

- [ ] Privacy policy
- [ ] Terms & conditions
- [ ] Remove frontend secrets
- [ ] Enforce HTTPS
- [ ] Cookie consent banner
- [ ] Meta titles/descriptions
- [ ] Social preview image
- [ ] Favicon
- [ ] Sitemap and robots.txt
- [ ] Image alt text
- [ ] Image compression
- [ ] Page load speed check
- [ ] Color contrast fixes
- [ ] Mobile responsiveness
- [ ] Custom 404 page
- [ ] Broken link fixes
- [ ] Form validation
- [ ] Spam protection
- [ ] Analytics setup
- [ ] Single clear CTA
