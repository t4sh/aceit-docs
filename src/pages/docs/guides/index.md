The starter favors plain Markdown for content and a small set of HTML patterns for richer pages.

## Choose a guide

- [Write a page](/guides/writing-pages/) explains front matter and navigation.
- [Components](/guides/components/) shows copyable content patterns.
- [Customize the theme](/guides/theming/) explains the color system.
- [Deploy your site](/guides/deploying/) covers GitHub Pages, Cloudflare Pages, and Vercel.

Each guide is a normal Markdown file. You can rename or remove these examples when you add real documentation.
