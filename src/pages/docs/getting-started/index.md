Aceit Docs keeps content, layouts, and behavior separate, following the shape of Aceit Kit Starter. Most documentation work happens in `src/pages/docs/`.

## Quick path

1. Install dependencies with `npm install`.
2. Run `npm run dev` for a local preview.
3. Edit a Markdown file in `src/pages/docs/`.
4. Run `npm run build` before publishing.

The generated site lives in `out/`. You can deploy that folder to any static host.
